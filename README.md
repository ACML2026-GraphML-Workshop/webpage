# GML 2026 Workshop Website

Static website for **Graph Machine Learning: Foundations, Frontiers, and Applications**, an ACML 2026 workshop.

## Files

- `index.html` - single-page workshop website
- `styles.css` - responsive visual design
- `script.js` - mobile navigation behavior
- `assets/graph-ml-hero.png` - generated hero/social visual
- `.nojekyll` - GitHub Pages compatibility marker

## Publish With GitHub Pages

1. Create a new GitHub repository, for example `acml-gml-2026`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.

The site will be published at:

```text
https://<your-github-username>.github.io/acml-gml-2026/
```
